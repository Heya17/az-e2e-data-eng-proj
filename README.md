# Azure End-to-End Data Engineering Project

## Architecture
Source Data → ADF → ADLS Gen2 → Databricks → Synapse Analytics

## Technologies Used
- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Databricks (PySpark)
- Azure Synapse Analytics
- Azure Key Vault
- Terraform (Infrastructure as Code)

## Project Overview
Built a complete data pipeline processing Tokyo 2021 Olympics data.
Includes data ingestion, transformation and analytical querying.
